# IMchess

실전 중에는 침묵하고, 대국이 끝나면 집요하게 가르치는 개인 체스 코치.

## 현재 기능
- Chess.com 월간 PGN 가져오기
- Lichess 완료 대국 PGN 가져오기
- 로컬 PGN 파일 가져오기
- 대국 재생용 체스판
- 초반 / 중반 / 후반 학습 신호 분류
- 반복 약점 누적 및 대시보드
- 실제 대국 포지션에서 훈련 문제 생성
- 반응형 PC / 모바일 UI
- 실전 중 조언을 제공하지 않는 설계

## 실행

```bash
npm install
npm run dev
```

빌드:

```bash
npm run build
```

## 다음 엔진 단계

분석 정확도를 위해 브라우저 Stockfish WASM 워커를 붙일 자리와 데이터 모델을 분리할 예정입니다. 최종 분석은 사용자의 실제 수와 엔진 최선수의 평가 차이를 이용해 실수, 부정확, 전술 실패를 분류하고, 그 결과를 초반/중반/후반별 약점과 퀴즈에 연결합니다.

## 원칙

IMchess는 라이브 대국의 수 추천이나 실시간 평가를 제공하지 않습니다. 완료된 대국만 분석하고 학습에 사용합니다.
