# IMchess

언제든지 만나보세요.

## 현재 기능
- Chess.com 월간 PGN 가져오기
- Lichess 완료 대국 PGN 가져오기
- 로컬 PGN 파일 가져오기
- 대국 재생용 체스판
- 초반 / 중반 / 후반 학습 신호 분류
- 반복 약점 누적 및 대시보드
- 실제 대국 포지션에서 훈련 문제 생성
- 반응형 PC / 모바일 UI

## 실행

```bash
npm install
npm run dev
```

빌드:

```bash
npm run build
```

IMchess는 라이브 대국의 수 추천이나 실시간 평가를 제공하지 않습니다. 완료된 대국만 분석하고 학습에 사용합니다.
